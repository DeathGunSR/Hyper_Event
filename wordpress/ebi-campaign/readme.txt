اتصال سایت فروشگاه به سرویس مرکزی کمپین: شمارندهٔ واقعی فاکتورها، صفحهٔ کمپین، آرشیو
رسمی برندگان، پنل مدیریت دوره‌ها، قرعه‌کشی، مدیریت تصویر برنده و ارسال دستی پیامک.

== Description ==

این افزونه هیچ داده‌ای را مستقل از سرویس مرکزی نمی‌سازد. شمارنده، برندگان، دوره‌ها و
نتیجهٔ قرعه‌کشی همیشه از API مرکزی خوانده می‌شوند و عملیات مدیریتی با کلید نقش همان
توانایی به سرور فرستاده می‌شوند.

شورت‌کدها:

* `[ebi_campaign]` — صفحهٔ کمپین با شمارنده و وضعیت واقعی
* `[ebi_campaign_counter]` — شمارندهٔ فشرده
* `[ebi_winners per_page="10"]` — آرشیو برندگان

قواعد ثابت:

* هیچ پیامکی خودکار ارسال نمی‌شود؛ ارسال فقط دستی، با مجوز `ebi_send_sms` و تأیید صریح.
* اطلاعات کامل موبایل در خروجی عمومی نمایش داده نمی‌شود.
* در قطع ارتباط با سرویس، شمارندهٔ صفر جعل نمی‌شود.
* مجوز عملیات در سرور بررسی می‌شود، نه فقط با پنهان‌کردن دکمه.

== Installation ==

1. پوشهٔ `ebi-campaign` را در `wp-content/plugins/` قرار دهید یا زیپ را از پیشخوان نصب کنید.
2. افزونه را فعال کنید.
3. در «کمپین ابی → تنظیمات» آدرس سرویس مرکزی، شمارهٔ فرستنده و کلیدهای نقش را وارد کنید.
4. یک صفحه بسازید و شورت‌کد `[ebi_campaign]` را در آن قرار دهید.
