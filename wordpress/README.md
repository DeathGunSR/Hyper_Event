# افزونهٔ کمپین ابی (EbiCampaign) — نسخهٔ ۰.۳.۰

افزونهٔ اختصاصی وردپرس برای اتصال سایت `ebimarket.ir` به سرویس مرکزی کمپین.
تمام اعداد و وضعیت‌ها از API مرکزی خوانده می‌شوند؛ افزونه هیچ شمارنده، برنده یا دوره‌ای
را مستقل نمی‌سازد.

## نصب

1. پوشهٔ `ebi-campaign` را در `wp-content/plugins/` قرار دهید (یا فایل زیپ بستهٔ تحویل را از
   پیشخوان → افزونه‌ها → افزودن → بارگذاری افزونه نصب کنید).
2. افزونه را فعال کنید. فعال‌سازی، توانایی‌های زیر را به نقش مدیر اضافه می‌کند و نسخهٔ اسکیما
   را ثبت می‌کند؛ هیچ تغییری در هستهٔ وردپرس یا قالب انجام نمی‌شود.
3. در صفحهٔ «کمپین ابی → تنظیمات»، آدرس سرویس مرکزی، شمارهٔ فرستنده و کلیدهای نقش را وارد کنید.

| توانایی | کاربرد |
| --- | --- |
| `ebi_view_campaign` | مشاهدهٔ پنل، دوره‌ها، فاکتورها و قرعه‌کشی |
| `ebi_manage_campaign` | شروع/بستن دوره و تخصیص فاکتورهای انتظار |
| `ebi_review_invoice` | تصمیم روی فاکتورهای نیازمند بررسی |
| `ebi_run_lottery` | تثبیت مجموعه، انتخاب و نهایی‌سازی قرعه‌کشی |
| `ebi_publish_result` | انتشار عمومی نتیجه و مدیریت تصویر برنده |
| `ebi_view_private` | مشاهدهٔ شمارهٔ کامل برنده (با ثبت حسابرسی در سرویس مرکزی) |
| `ebi_send_sms` | ارسال **دستی** پیامک |

> پنهان‌بودن دکمه جایگزین کنترل سرور نیست. هر عملیات علاوه بر `current_user_can` و نونس،
> کلید نقش متناظر را به سرویس مرکزی می‌فرستد و سرویس مرکزی مجوز را دوباره بررسی می‌کند.

## صفحات عمومی

| شورت‌کد | کاربرد |
| --- | --- |
| `[ebi_campaign]` | صفحهٔ اصلی کمپین: شمارنده، نوار پیشرفت، وضعیت، آخرین نتیجه، راهنمای بله و قوانین |
| `[ebi_campaign_counter]` | شمارندهٔ فشرده برای برگه یا ویجت |
| `[ebi_winners per_page="10"]` | آرشیو رسمی برندگان با صفحه‌بندی و فیلتر `?ebi_round=2` |

ویژگی‌های `[ebi_campaign]`: `show_rules="no"`، `show_bale="no"`، `show_result="no"`.

رفتار در حالت‌های خاص:

- دورهٔ در حال جمع‌آوری: شمارنده و باقی‌مانده.
- دورهٔ تکمیل‌شده و منتظر قرعه‌کشی: شمارنده صفر نمی‌شود و پیام «در انتظار قرعه‌کشی» می‌آید.
- دورهٔ نیازمند بررسی مدیریتی: وضعیت مربوطه نمایش داده می‌شود.
- قطع ارتباط با API: پیام روشن «در دسترس نیست» و تأکید بر اینکه صفر بودن شمارنده نیست.
- دورهٔ بسته و دورهٔ بعد شروع‌نشده: شمارندهٔ دورهٔ تکمیل‌شده حفظ می‌شود.

## پنل مدیریت

زیرمنوهای «کمپین ابی»: وضعیت، دوره‌ها، نیازمند بررسی، فاکتورهای انتظار، قرعه‌کشی،
برندگان و تصاویر، پیامک، تنظیمات.

- **دوره‌ها**: شروع دوره (تأیید صریح + جلوگیری از درخواست تکراری)، بستن دوره، فهرست دوره‌ها.
- **نیازمند بررسی**: دلیل و شواهد، تصمیم اعتبار/ابطال با دلیل.
- **فاکتورهای انتظار**: فهرست `Held` و تخصیص صریح به یک دوره.
- **قرعه‌کشی**: تثبیت مجموعه، انتخاب، نهایی‌سازی، لغو، سند و راستی‌آزمایی.
- **برندگان**: انتشار نتیجه، نام نمایشی، بارگذاری/حذف تصویر با کنترل نوع و حجم.
- **پیامک**: قالب‌ها، پیش‌نمایش و ارسال دستی (پایین).

## پیامک ملی‌پیامک (ارسال کاملاً دستی)

- **هیچ** رویدادی (تکمیل دوره، قرعه‌کشی، ثبت برنده) پیامک نمی‌فرستد. کلاس پیامک هیچ
  `add_action`، `wp_schedule_event` یا صف retry ندارد.
- مسیر ارسال: انتخاب قالب → انتخاب گیرنده (برندهٔ یک دوره یا شمارهٔ آزمایشی) → بررسی متن
  و تعداد → تأیید صریح → ارسال. مجوز `ebi_send_sms` در سرور بررسی می‌شود.
- متغیرهای مجاز: `{name}`، `{mobile}`، `{round}`، `{points}`، `{invoice_count}`، `{prize}`،
  `{date}`، `{store}`، `{support}`. متغیر ناشناخته یا مقدار خالی پیش از ارسال خطا می‌دهد.
- متن پیش‌نمایش دقیقاً همان متنی است که ارسال می‌شود (هر دو از یک تابع جایگزینی).
- پاسخ موفق، ناموفق و **نامشخص** جدا ثبت می‌شوند. Timeout یا پاسخ مبهم به «نامشخص»
  می‌رود و **خودکار تکرار نمی‌شود**؛ بررسی و اقدام بعدی با کاربر مجاز است.
- شمارهٔ کامل برنده فقط با کلید `privacy.contact` از مسیر مدیریتی خوانده می‌شود و گزارش
  محلی فقط شمارهٔ سانسورشده را نگه می‌دارد.
- تنظیمات: نام کاربری، شمارهٔ فرستنده، آدرس سرویس و رمز حساب. رمز در گزینهٔ محرمانه ذخیره
  می‌شود (یا ثابت `EBI_CAMPAIGN_SMS_PASSWORD` در `wp-config.php`) و هرگز چاپ نمی‌شود.

## کلیدهای سرویس‌به‌سرویس

اگر این ثابت‌ها در `wp-config.php` تعریف شوند، اولویت دارند و در پایگاه داده ذخیره نمی‌شوند:

```php
define( 'EBI_CAMPAIGN_ADMIN_KEY', '...' );
define( 'EBI_CAMPAIGN_CAMPAIGN_KEY', '...' );
define( 'EBI_CAMPAIGN_REVIEW_KEY', '...' );
define( 'EBI_CAMPAIGN_LOTTERY_KEY', '...' );
define( 'EBI_CAMPAIGN_PUBLISH_KEY', '...' );
define( 'EBI_CAMPAIGN_PRIVACY_KEY', '...' );
define( 'EBI_CAMPAIGN_SMS_PASSWORD', '...' );
```

صفحهٔ تنظیمات فقط چهار رقم آخر را نشان می‌دهد.

## آزمون‌ها

آزمون‌ها روی وردپرس واقعی محلی اجرا می‌شوند و به یک سرویس مرکزی جعلی نیاز دارند:

```bash
# ۱) سرویس جعلی (پنجرهٔ جدا)
php -S 127.0.0.1:8099 wordpress/tests/mock-api/router.php

# ۲) اتصال افزونه به وردپرس (یک‌بار)
ln -s "$PWD/wordpress/ebi-campaign" /path/to/wordpress/wp-content/plugins/ebi-campaign

# ۳) آزمون
WP_ROOT=/path/to/wordpress EBI_MOCK=http://127.0.0.1:8099 php wordpress/tests/plugin-test.php

# گزارش محیط واقعی
WP_ROOT=/path/to/wordpress php wordpress/tests/smoke.php
```

پوشش آزمون (۹۹ بررسی): فعال‌سازی، توانایی‌ها، پاک‌سازی تنظیمات، نمایش کلید سانسورشده،
شورت‌کدها در همهٔ حالت‌ها، کش و بی‌اعتبارسازی، رفتار قطع ارتباط، آرشیو برندگان و
صفحه‌بندی، جلوگیری از XSS، اعتبارسنجی تصویر، مجوز/نونس/تأیید عملیات، قالب و متغیرهای
پیامک، پیش‌نمایش، ارسال دستی، ثبت گزارش، نامشخص بدون retry و اثبات نبود ارسال خودکار.

## محدودیت‌ها

- آزمون پیامک با انتقال‌دهندهٔ جعلی انجام شده است؛ ارسال واقعی به ملی‌پیامک بدون کلید
  حساب و شمارهٔ آزمایشی مجاز اجرا نشد.
- آدرس تصویر برنده باید روی همین سایت باشد؛ میزبانی بیرونی پذیرفته نمی‌شود.
- افزونه در محیط محلی (WordPress 7.1.3، PHP 8.2، Woodmart Child) آزموده شده است. تست
  مرورگر روی سایت عملیاتی انجام نشده و HTTPS عملیاتی باید توسط میزبان تأمین شود.
